# دليل الحسابات الشجري الموحد (Chart of Accounts - COA)
### نظام شركة رواسي عدن للهندسة والمقاولات (Node.js + Express + SQLite/MySQL)

---

## 📌 1. نظرة عامة والمعمارية المحاسبية (Accounting Architecture)

تم تصميم وبناء **دليل الحسابات الشجري الموحد** لشركة رواسي عدن وفق معايير المحاسبة الدولية (**IFRS**) والمعايير المالية المعتمدة في شركات المقاولات والهندسة. يحتوي الدليل على **112 حساباً معيارياً** مبوبة في **5 مستويات هرمية دقيقة (Levels 1 to 5)** تضمن الفصل المحاسبي الكامل بين عناصر المركز المالي وقائمة الأرباح والخسائر.

---

## ⚖️ 2. التصحيحات المحاسبية الجوهرية (Crucial Accounting Fixes)

أثناء فحص ملف الإكسل المصدري، تم رصد عدة مشاكل هيكلية ومحاسبية وتمت معالجتها برمجياً ومحاسبياً على النحو التالي:

### 1. فصل وتصحيح حقوق الملكية (Equity Isolation):
- **المشكلة:** كان حساب `211` (حقوق الملكية) مصنفاً خطأً كـ فرع تابع للالتزامات طويلة الأجل `21` (Liability).
- **التصحيح وفق IFRS:** وفقاً للمعادلة المحاسبية الأساسية `الأصول = الالتزامات + حقوق الملكية`، تم تعديل التصنيف النوعي لكافة حسابات حقوق الملكية ومشتقاتها (`211`, `21101`, `21101001`, `21101002`, `21102`, `21102001`, `21102002`) ليصبح نوعها المعتمد هو:
  `type = 'equity'` مع توجيهها إلى الميزانية العمومية `report_type = 'balance_sheet'`.

### 2. معالجة مجمعات الإهلاك كـ أصل مقابل (Contra-Asset):
- **المشكلة:** كان حساب `21103` (مجمعات الإهلاك) مدرجاً خطأً ضمن حقوق الملكية.
- **التصحيح وفق IFRS:** مجمعات الإهلاك المحاسبية طبيعتها دائنة لكنها تتبع الأصول وتُعرض في الميزانية العمومية مطروحةً من تكلفة الأصول الثابتة للوصول إلى صافي القيمة الدفترية.
- **الحل التقني:** تم تصنيف الحساب `21103` والفرعي `21103001` كـ:
  `type = 'asset'` مع تفعيل راية الحساب المقابل `is_contra = 1`، وتقرير `report_type = 'balance_sheet'`.

### 3. دعم العملات المتعددة (Multi-Currency Support):
- تم تنظيف التنسيق النصي للعملات بحذف الفواصل العالقة (`YER,` ➔ `YER`).
- تم توسيع دعم العملات ليشمل الريال السعودي والدولار (`YER,SAR,USD`) للحسابات الحيوية والنقدية مثل البنك المركزي اليمني (`12201002`)، رأس المال (`21101001`)، إيرادات النشاط وعمولات التحصيل (`41101001`)، وفروق العملة (`41203002`).

### 4. تصحيح كود الحساب الأب (Parent Code Normalization):
- تم استبدال القيمة `0` المخصصة للحسابات الرئيسية لتُخزن كقيمة فارغة `NULL`، مما يحقق السلامة التامة للعلاقات الشجرية ويمنع أخطاء قيود المفاتيح الأجنبية.

### 5. تصحيح الأخطاء اللغوية والإملائية:
- تصحيح: `"مجمع الاهكلاكات"` ➔ `"مجمع الإهلاكات"`.
- تصحيح: `"مجمعات الاهلاك"` ➔ `"مجمعات الإهلاك"`.
- تصحيح: `"مصاريف التاسيس"` ➔ `"مصاريف التأسيس"`.
- تصحيح التكرار والخطأ اللغوي في: `"الاصول غير المتداوله"` و `"الاصول الغير متداوله"` ➔ اعتماد التسمية الفصحى الموحدة: `"الأصول غير المتداولة"`.

## 🏗️ 3. قواعد الترقيم الهرمي ومستويات الشجرة (Tree Hierarchy & Levels)

تتبع شجرة الحسابات نظام ترقيم تصاعدي دقيق ومحكم:

| المستوى (Level) | الوصف المحاسبي | طول الكود | مثال | يقبل قيود مباشرة؟ (`is_posting`) |
| :---: | :--- | :---: | :--- | :---: |
| **Level 1** | الحسابات الرئيسية الكبرى | **رقم واحد** | `1` الأصول، `2` الالتزامات، `3` المصاريف، `4` الإيرادات | ❌ لا (تجميعي) |
| **Level 2** | الحسابات العامة | **رقمان** | `11` الأصول الثابتة، `12` الأصول المتداولة | ❌ لا (تجميعي) |
| **Level 3** | الحسابات المساعدة | **3 أرقام** | `111` الأثاث، `121` الصناديق، `122` البنوك | ❌ لا (تجميعي) |
| **Level 4** | الحسابات التحليلية | **5 أرقام** | `11101` الأثاث المكتبي، `12101` صندوق الإدارة | ❌ لا (تجميعي) |
| **Level 5** | الحسابات الفرعية الحركية | **8 أرقام** | `11101001` الأثاث المكتبي، `12101001` صندوق الإدارة | ✅ **نعم (حساب طرفي)** |

> **قاعدة ذهبية:** فقط الحسابات من **Level 5** تكون `is_posting = 1` وتستقبل القيود اليومية وسندات الصرف والقبض وفواتير المشتريات. كافة المستويات من 1 إلى 4 هي مستويات تجميعية للتقارير والقوائم المالية.

## 🗄️ 4. مخطط جدول الحسابات المحدث (`accounts`)

```sql
CREATE TABLE accounts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,      -- في MySQL: INT AUTO_INCREMENT
    code VARCHAR(20) NOT NULL UNIQUE,          -- كود الحساب الفريد
    name VARCHAR(200) NOT NULL,                -- اسم الحساب بالعربية
    type VARCHAR(30) NOT NULL,                 -- asset, liability, equity, expense, revenue
    parent_code VARCHAR(20) NULL,              -- كود الحساب الأب (نصي)
    parent_id INTEGER NULL,                    -- معرف الحساب الأب (رقمي للتوافق الداخلي)
    level INTEGER NOT NULL,                    -- رتبة الحساب (1 إلى 5)
    is_posting BOOLEAN NOT NULL DEFAULT 0,     -- 1 للحسابات الطرفية الحركية (Level 5) فقط
    currencies TEXT DEFAULT 'YER',             -- قائمة العملات المفصولة بفواصل
    report_type VARCHAR(50) NOT NULL,          -- balance_sheet أو income_statement
    inclusion TEXT NULL DEFAULT '=',           -- التضمين للتوافق مع الملف الأصلي
    is_contra BOOLEAN NOT NULL DEFAULT 0,      -- 1 للحسابات المقابلة (مثل مجمعات الإهلاك)
    is_active BOOLEAN NOT NULL DEFAULT 1,      -- حالة التفعيل
    balance REAL DEFAULT 0,                    -- رصيد الحساب المالي
    status VARCHAR(20) DEFAULT 'active',       -- حالة الحساب
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### الفهارس المعتمدة (Performance Indexes):
- `idx_accounts_code` (فريد UNIQUE)
- `idx_accounts_parent_code`
- `idx_accounts_parent_id`
- `idx_accounts_type`
- `idx_accounts_is_posting`
- `idx_accounts_level`
- `idx_accounts_report_type`

## 🔍 7. نماذج واستعلامات مالية SQL جاهزة

### 1. استعلام قائمة الحسابات الطرفية المتاحة لسندات القبض/الصرف والقيود:
```sql
SELECT id, code, name, currencies, type
FROM accounts
WHERE is_posting = 1 AND is_active = 1
ORDER BY code ASC;
```

### 2. استعلام شجرة الحسابات مع اسم الحساب الأب:
```sql
SELECT 
    child.code, 
    child.name, 
    child.level, 
    child.type,
    parent.code AS parent_code,
    parent.name AS parent_name
FROM accounts child
LEFT JOIN accounts parent ON child.parent_code = parent.code
ORDER BY child.code ASC;
```

### 3. تقرير الميزانية العمومية (Balance Sheet Accounts):
```sql
SELECT 
    type,
    code, 
    name, 
    CASE WHEN is_contra = 1 THEN 'خصم من الأصول (Contra)' ELSE 'عادي' END AS presentation,
    balance
FROM accounts
WHERE report_type = 'balance_sheet' AND is_posting = 1
ORDER BY code ASC;
```

### 4. تقرير قائمة الدخل والأرباح والخسائر (Income Statement Accounts):
```sql
SELECT 
    type,
    code, 
    name, 
    balance
FROM accounts
WHERE report_type = 'income_statement' AND is_posting = 1
ORDER BY code ASC;
```
